## 2. User Flow

### 2.1 신규 검색

```mermaid
flowchart TD
    A[AI 초기 화면] --> B{질문 방식 선택}
    B -->|직접 입력| C[질문 입력]
    C --> D[전송]
    B -->|추천 질문| E[추천 질문 선택]
    D --> F[AI 답변 결과]
    E --> F
    F --> G[답변 확인]
```

### 2.2 후속 질문

```mermaid
flowchart TD
    A[AI 답변 결과] --> B[질문 입력]
    B --> C[전송]
    C --> D[새 AI 답변]
    D --> E{추가 질문 여부}

    E -->|Yes| B
    E -->|No| F[검색 종료]
```

### 2.3 검색 서비스 이동

```mermaid
flowchart TD
    A[AI 화면] --> B[블로그]
    A --> C[카페]
    A --> D[클립]
    A --> E[이미지]
    A --> F[지식iN]
    A --> G[동영상]
    A --> H[쇼핑]

    B --> I[해당 검색 영역]
    C --> I
    D --> I
    E --> I
    F --> I
    G --> I
    H --> I
```
